# Title SOP

Run this on every kicker, page title, section title, product-card title, close title, and FAQ header. If the title is also a numbered reason or the page H1, run `headline-sop.md` as well. Both must pass. Memory is not the SOP. This file is.

Dave, 2026-08-31, listicle. Fake magazine kickers and generic "Five Reasons..." titles do not say anything. A title that only labels the module is clutter.

## What a title is

A title names the next block and still SAYS something. It is not a folder name. It is not chrome. Ogilvy put the promise in the line people actually read. A kicker that says `Kitchen Essentials · Popsmith Review` is costume. A card titled `The Starter Set` can stay, because that is the offer's name. A section titled `Owners say it best` is a shrug.

## Tests (all must pass)

1. **Job.** What does this block exist to do. The title should make that job visible. If you could swap in "Section 3" and lose nothing, kill it.
2. **Says something.** Not a category lecture (`Five Reasons the Popsmith Earns Its Place on Your Counter`). Not a fake masthead. Not "As Seen In" unless the strip is actually press marks (that one may stay, it is a true label for a true strip).
3. **Not a second headline.** The title must not steal the H1's job or repeat it in softer words. One stop per scroll-stop. Titles move her into the block.
4. **Not a spec chip.** `Stainless steel` is not a title. `Dishwasher safe` is not a title. Those are body or a proof row.
5. **Swap.** If the title fits a pan brand's lander with the name changed, it is generic. Exception: true proper nouns (The Starter Set, The Popper, Oprah's Favorite Things 2023).
6. **Clutter.** Partner hates extra words. If the title is doing a throat-clear (`Here's why`, `Owners say it best`, `Questions, answered` can stay as FAQ only because it is a true label), cut it.
7. **Voice.** No pot. Complete words, not fragments. No dare. No persona names. No "you just watched."

## Fail examples (do not rewrite these back in)

- Kitchen Essentials · Popsmith Review
- Five Reasons the Popsmith Earns Its Place on Your Counter
- Owners say it best
- Popcorn night is waiting
- Value Propositions
- Simply the Best (as a title over a quote)

## Pass shape

True names: The Starter Set. The Popper. As Seen (& Loved) In: (only over real marks).
Section titles that are also reasons: those are headlines. They must pass `headline-sop.md`.
FAQ: the question is the title. It must be the question she actually has (`Isn't $229 a lot for a popcorn maker?` is a real objection. `Will it burn the popcorn?` is a real objection).
