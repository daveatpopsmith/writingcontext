# AI around the work, not as the hook factory

**Source:** Foxwell blog (https://www.foxwelldigital.com/blog/leveraging-ai-for-creative-breakthroughs-without-losing-originality) + go-deeper episode AI DTC WTF / Matthew Gattozzi (https://www.youtube.com/watch?v=J27ANxLyeOs). Tarly notes 2026-09-07 and 2026-09-08. Operator opinion, not Popsmith measured time. Filed 2026-09-08; deepened 2026-09-08.

**Date added:** 2026-09-08

**Principle:**
AI’s real ROI in creative is admin and coordination (recaps, scheduling, brand-context upkeep, claim fact-check), not ideation. Ideation stays human. Models are retroactive — they default to what already worked. Breakthrough angles come from life, culture, and customer talk. Account data ranks hypotheses and de-risks early statics; it does not invent the next persona. Living brand + **format-specific** context docs (statics / UGC / studio) keep drafts on-brand. Humans decide when to break the playbook. Use AI to iterate winners and duplicate volume; free humans for net-new.

**Popsmith failure mode:**
Using AdNova alone as the idea machine. Asking a model for the next pillar. Letting agents invent hooks without a named hypothesis. Treating Nano Banana / gen prompts as concept work instead of comps and missing stills. Building feature-max SaaS reporting when a thin “what works + tagged why” table would do. Trusting first AI draft end-to-end.

**One line we might run:**
Reclaim creative time with AI around the work. Territory, hypothesis, and hook stay human. Performance reads rank; they don’t invent. Format context docs; humans break the rules on purpose.

**How Roma uses this (operating):**
1. Briefs: name concept/territory/frames first; AI may scaffold and fact-check against brand context — never originate the angle.
2. Monday packs: AdNova is yes/no on funded hypotheses, not a prompt for “what’s next.”
3. Image prompts: comps and missing stills only — not concept.
4. Optional later: thin hooks library from saved winners (verbal / on-screen / visual) for reuse with new personas — only after Dave asks.
5. Custom Meta reporting: only if current dashboards waste iteration time; keep it thin (tags + retention), not SaaS feature-max. Hagen owns buy-vs-build.

**Where this fails:**
Their 40–60%→~20% admin cut, Verdana savings, and client anecdotes are Goodo claims, not our calendar. Wild formats that skip context docs are their call; we still ban AI people and invented kitchens.
