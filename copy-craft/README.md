## How to add a lesson

1. One principle per file. If you have two, write two files.
2. Filename: `lessons/YYYY-MM-DD-slug.md`
3. Every file must have these headings, in this order:

```
# Title (one line, the principle)
Source:
Date added:
Principle:
Popsmith failure mode:
One line we might run:
Where this fails on Popsmith:
```

4. Paraphrase. Cite the work + year, or URL + fetch date. No verbatim book chapters, lyrics, or long quotes. Short phrases under ~10 words are fine if attributed.
5. Add a one-line entry to `log.md` the same day.
6. Do not invent Popsmith stats. Do not paste customer quotes you did not find in `popsmith-contexts/`.

## Rule

One principle per file. Specific. Short. No corporate filler.
