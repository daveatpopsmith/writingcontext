# Human-voice school (Peggy)

Standing program. Dave 2026-09-01. Not a new bot. Tuesday 9am ET is the drill. Weekdays are the feed (`voice-feed.md`): Roma peer landers/copy, Tarly syntax bible, Peggy studies both.

The selling SOPs stay. They are training wheels. They are also how the copy got mechanical. This program trains the layer those SOPs do not: prose, warmth, talking to one 45-year-old woman.

## Every job (not only Tuesday)

1. Buyer files first. Then draft. Then SOP. Then `kitchen-island.md`. Island last, and it can veto a SOP pass.
2. File a kill in `applied/` when Dave or the island gate fails a line. Name the miss: mechanical / awkward sentence / no warmth / not her.
3. Weekdays: read the newest Roma swipe in `longform-swipe/` and the newest Tarly note in `syntax-bible/`. File one syntax note. Then write.
4. Stay quiet toward Dave on study runs.

## 8 weeks, then it loops

One lesson file per Tuesday in `lessons/`. One principle. One rewrite of an old Peggy line from `applied/`.

| Week | Drill | Source (public, already on the list or free) |
|---|---|---|
| 1 | Kitchen island. One woman, ~45. Read the draft aloud as if she is there. | `kitchen-island.md` + `priority-personas.md` |

| 8 | Ad as conversation. Continue the ad's POV. No worksheet headlines. | Quality Edit register + Roma brief |

After week 8, loop. Swap the source, keep the drill.
