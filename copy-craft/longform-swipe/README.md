# Long-form swipe (talk like a person)

Dave 2026-09-01: this register matters for Popsmith articles and long-form landers. Quality Edit / Our Place is the seed. Collect as many keepers as we can from other brands. Paraphrase. Never paste the piece.

## What a keeper is

A person is talking. They start in a real kitchen (or the equivalent object-life), they are skeptical or already own the tired version, they try the thing, they tell you what happened. Sentences lean on the ones before them. Because / so / then. Subheads are turns in a conversation, not verdicts.

Core Buyer: Discerning Collector. She already owns Le Creuset. Not talent. Not millennial unboxing.

## What is not a keeper

- Numbered feature list as the piece
- Brand PDF / "we believe" / tribe
- Wirecutter spec sheet
- Toxin / Zone 4 safety lecture
- Stacked verdicts with no person in them
- Fake magazine chrome we would copy (byline costume, "in partnership" as the voice)
- Homecoming nostalgia as the claim
- "Last X you'll buy" permanence

Steal the talk. Do not steal the costume.
