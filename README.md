# Popsmith writing context

Portable writing context for **Peggy** (and anyone writing in Popsmith voice). Use it in Claude, Cursor, Astra, or any AI tool that can take a folder or repo as project knowledge.

This pack is the school, the voice libraries, and the process recipes — not AdNova metrics or performance tooling.

## Folder map

| Folder | What it is |
|--------|------------|
| `copy-craft/` | School / SOPs / lessons — how we write (headlines, body, anti-AI tells, applied examples, swipe, syntax). |
| `copy-context/` | Talk-like-her + brand-talk libraries — voice, transcripts, brand notes, host/popcorn sensory language, decisions. |
| `skills/` | Process recipes exported from agent skills (commission, draft, edit, rewrite, anti-slop, voice profile, learn-from-shipped). |

## How to use

1. **Clone** this private repo (under `daveatpopsmith`), or connect it as a project knowledge / context source in your AI tool.
2. Point the model at the folders that match the job (e.g. voice work → `copy-context/`; craft SOPs → `copy-craft/`; workflow → `skills/`).
3. When shipping copy: **paraphrase**. Do **not** paste source transcripts into customer-facing copy.
